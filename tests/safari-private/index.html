Safari Private Browsing / IndexedDB diagnostics

This page compares the IndexedDB transaction shapes involved in PouchDB startup, then runs document and attachment lifecycles through both browser adapters. Run it in regular and private Safari windows and save both logs.

Build the local browser bundles with node bin/build-pouchdb.js, start npm run launch-dev-server, then open http://127.0.0.1:8000/tests/safari-private/. A web server is required for the worker diagnostic.

Each operation has a bounded timeout. A timeout means an IndexedDB request, transaction, or PouchDB task queue did not reach a terminal state; it does not silently advance as a success.
